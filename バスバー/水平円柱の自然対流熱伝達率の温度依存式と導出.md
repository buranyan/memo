# 水平円柱の自然対流熱伝達率の温度依存式

## 1. 解析対象

静止空気中に円柱が置かれ、その中心軸が水平である場合を考える。

円柱直径を

\[
D\quad[\mathrm{m}]
\]

円柱長さを

\[
L\quad[\mathrm{m}]
\]

円柱表面温度を

\[
T_s\quad[\mathrm{K}]
\]

周囲空気温度を

\[
T_\infty\quad[\mathrm{K}]
\]

とする。

以下では円柱は十分長く、端面からの放熱は無視し、円柱側面からの自然対流のみを取り扱う。

---

# 2. 対流による放熱量

対流による熱流はNewtonの冷却則によって

\[
Q_{\mathrm{conv}}
=
hA(T_s-T_\infty)
\]

と表される。

ここで、

\[
h
=
\text{平均対流熱伝達率}
\quad
[\mathrm{W/(m^2K)}]
\]

である。

円柱側面積は

\[
A=\pi DL
\]

なので、

\[
Q_{\mathrm{conv}}
=
h\pi DL(T_s-T_\infty)
\]

となる。

したがって円柱単位長さ当たりでは、

\[
\boxed{
\frac{Q_{\mathrm{conv}}}{L}
=
h\pi D(T_s-T_\infty)
}
\]

となる。

熱回路として表現すれば、

\[
Q_{\mathrm{conv}}
=
\frac{T_s-T_\infty}{R_{\mathrm{conv}}}
\]

なので、

\[
\boxed{
R_{\mathrm{conv}}
=
\frac{1}{h\pi DL}
}
\]

となる。

したがって、自然対流を温度依存で扱うには、

\[
h=h(T_s,T_\infty,D)
\]

とすればよい。

---

# 3. なぜ自然対流でRayleigh数が現れるか

自然対流は、温度によって空気密度が変化し、その密度差によって浮力が生じることで発生する。

非圧縮性近似およびBoussinesq近似を用いると、連続の式は

\[
\nabla\cdot\mathbf{u}=0
\]

である。

運動方程式は

\[
\rho
(\mathbf{u}\cdot\nabla)\mathbf{u}
=
-\nabla p
+
\mu\nabla^2\mathbf{u}
+
\rho g\beta(T-T_\infty)\mathbf{e}_g
\]

となる。

ここで、

\[
\mu=\text{粘性係数}
\]

\[
\beta=\text{体膨張係数}
\]

である。

エネルギー方程式は

\[
\mathbf{u}\cdot\nabla T
=
\alpha\nabla^2T
\]

であり、

\[
\alpha
=
\frac{k}{\rho c_p}
\]

は熱拡散率である。

代表長さを円柱直径 \(D\)、代表温度差を

\[
\Delta T=T_s-T_\infty
\]

とする。

速度の代表値として

\[
U_0=\frac{\alpha}{D}
\]

を用いて無次元化する。

無次元量を

\[
\mathbf{x}^*
=
\frac{\mathbf{x}}{D}
\]

\[
\mathbf{u}^*
=
\frac{\mathbf{u}D}{\alpha}
\]

\[
\theta
=
\frac{T-T_\infty}{T_s-T_\infty}
\]

とする。

これを運動方程式に代入する。

慣性項は概略

\[
\rho\frac{U_0^2}{D}
=
\rho\frac{\alpha^2}{D^3}
\]

となる。

粘性項は

\[
\mu\frac{U_0}{D^2}
=
\mu\frac{\alpha}{D^3}
\]

である。

両者の比は

\[
\frac{\rho\alpha^2/D^3}
     {\mu\alpha/D^3}
=
\frac{\rho\alpha}{\mu}
\]

である。

動粘度

\[
\nu=\frac{\mu}{\rho}
\]

を使えば、

\[
\frac{\rho\alpha}{\mu}
=
\frac{\alpha}{\nu}
=
\frac{1}{Pr}
\]

となる。

ここでPrandtl数を

\[
\boxed{
Pr=\frac{\nu}{\alpha}
}
\]

と定義する。

一方、浮力項と粘性項の比は

\[
\frac{
\rho g\beta\Delta T
}{
\mu\alpha/D^3
}
\]

であり、

\[
=
\frac{
\rho g\beta\Delta TD^3
}{
\mu\alpha
}
\]

となる。

\[
\mu=\rho\nu
\]

なので、

\[
=
\frac{
g\beta\Delta TD^3
}{
\nu\alpha
}
\]

となる。

これをRayleigh数と定義する。

したがって、

\[
\boxed{
Ra_D
=
\frac{
g\beta\Delta TD^3
}{
\nu\alpha
}
}
\]

である。

また、

\[
Pr=\frac{\nu}{\alpha}
\]

なので、

\[
Ra_D
=
\frac{
g\beta\Delta TD^3Pr
}{
\nu^2
}
\]

とも書くことができる。

Grashof数

\[
Gr_D
=
\frac{
g\beta\Delta TD^3
}{
\nu^2
}
\]

を定義すると、

\[
\boxed{
Ra_D=Gr_DPr
}
\]

となる。

したがって自然対流の熱伝達は基本的に

\[
Nu=f(Ra,Pr)
\]

という形で整理できる。

---

# 4. Nusselt数と熱伝達率

Nusselt数は

\[
\boxed{
Nu_D
=
\frac{hD}{k}
}
\]

と定義される。

したがって、

\[
\boxed{
h
=
\frac{k}{D}Nu_D
}
\]

である。

つまり自然対流問題は、

\[
Ra_D
\]

と

\[
Pr
\]

を計算してNusselt数を求めれば、熱伝達率 \(h\) が求まることになる。

---

# 5. 空気物性を評価する温度

自然対流では円柱表面温度と周囲温度が異なる。

空気物性をどちらの温度で評価するかを決める必要がある。

一般に膜温度

\[
\boxed{
T_f
=
\frac{T_s+T_\infty}{2}
}
\]

を使用する。

例えば、

\[
T_s=80^\circ\mathrm{C}
\]

\[
T_\infty=25^\circ\mathrm{C}
\]

ならば、

\[
T_f
=
\frac{80+25}{2}
=
52.5^\circ\mathrm{C}
\]

である。

絶対温度では、

\[
T_f
=
52.5+273.15
=
325.65\ \mathrm{K}
\]

となる。

以下の空気物性は、この \(T_f\) で評価する。

---

# 6. 空気密度

大気圧付近の空気を理想気体とすると、

\[
p=\rho RT_f
\]

である。

したがって、

\[
\boxed{
\rho(T_f)
=
\frac{p}{RT_f}
}
\]

となる。

空気の気体定数を

\[
R=287.05\ \mathrm{J/(kgK)}
\]

とする。

標準大気圧の場合、

\[
p=101325\ \mathrm{Pa}
\]

である。

---

# 7. 体膨張係数

体膨張係数は

\[
\beta
=
-\frac{1}{\rho}
\left(
\frac{\partial\rho}{\partial T}
\right)_p
\]

と定義される。

理想気体では、

\[
\rho=\frac{p}{RT}
\]

なので、

\[
\frac{\partial\rho}{\partial T}
=
-\frac{p}{RT^2}
\]

である。

ここで、

\[
\rho=\frac{p}{RT}
\]

を用いると、

\[
\frac{\partial\rho}{\partial T}
=
-\frac{\rho}{T}
\]

となる。

したがって、

\[
\beta
=
-\frac{1}{\rho}
\left(-\frac{\rho}{T}\right)
\]

より、

\[
\boxed{
\beta
=
\frac{1}{T_f}
}
\]

となる。

---

# 8. 空気粘性係数の温度依存性

空気の粘性係数はSutherland式によって近似できる。

\[
\boxed{
\mu(T_f)
=
\mu_0
\left(
\frac{T_f}{T_0}
\right)^{3/2}
\frac{T_0+S_\mu}
     {T_f+S_\mu}
}
\]

空気について、

\[
\mu_0
=
1.716\times10^{-5}
\ \mathrm{Pa\,s}
\]

\[
T_0=273\ \mathrm{K}
\]

\[
S_\mu=111\ \mathrm{K}
\]

を使用する。

したがって、

\[
\boxed{
\mu(T_f)
=
1.716\times10^{-5}
\left(
\frac{T_f}{273}
\right)^{3/2}
\frac{273+111}
     {T_f+111}
}
\]

である。

Sutherland式とこの空気用定数はNASAおよびCOMSOLの資料にも示されている。

---

# 9. 動粘度

動粘度は

\[
\nu=\frac{\mu}{\rho}
\]

である。

したがって、

\[
\boxed{
\nu(T_f)
=
\frac{\mu(T_f)}
     {\rho(T_f)}
}
\]

である。

先ほど求めた

\[
\rho
=
\frac{p}{RT_f}
\]

を代入すると、

\[
\nu
=
\mu
\frac{RT_f}{p}
\]

となり、

\[
\boxed{
\nu(T_f)
=
\frac{\mu(T_f)RT_f}{p}
}
\]

となる。

---

# 10. 空気熱伝導率の温度依存性

空気の熱伝導率についてもSutherland型の近似式を使用する。

\[
\boxed{
k(T_f)
=
k_0
\left(
\frac{T_f}{T_0}
\right)^{3/2}
\frac{T_0+S_k}
     {T_f+S_k}
}
\]

空気の場合、

\[
k_0
=
0.0241\ \mathrm{W/(mK)}
\]

\[
T_0=273\ \mathrm{K}
\]

\[
S_k=194\ \mathrm{K}
\]

なので、

\[
\boxed{
k(T_f)
=
0.0241
\left(
\frac{T_f}{273}
\right)^{3/2}
\frac{273+194}
     {T_f+194}
}
\]

となる。

この空気用の熱伝導率Sutherland定数もCOMSOL資料に示されている。

---

# 11. 熱拡散率

熱拡散率は、

\[
\boxed{
\alpha
=
\frac{k}
     {\rho c_p}
}
\]

である。

したがって、

\[
\alpha(T_f)
=
\frac{
k(T_f)
}{
\rho(T_f)c_p
}
\]

となる。

今回の25～150℃程度の熱設計では、

\[
c_p
\simeq
1007\ \mathrm{J/(kgK)}
\]

と近似する。

したがって、

\[
\boxed{
\alpha(T_f)
=
\frac{
k(T_f)
}{
\rho(T_f)\,1007
}
}
\]

となる。

---

# 12. Prandtl数

Prandtl数は、

\[
Pr
=
\frac{\nu}{\alpha}
\]

である。

\[
\nu
=
\frac{\mu}{\rho}
\]

および

\[
\alpha
=
\frac{k}{\rho c_p}
\]

を代入すると、

\[
Pr
=
\frac{\mu/\rho}
{k/(\rho c_p)}
\]

となる。

分子分母の \(\rho\) が消去され、

\[
\boxed{
Pr(T_f)
=
\frac{
\mu(T_f)c_p
}{
k(T_f)
}
}
\]

となる。

空気ではこの値はおおむね0.7程度であるが、今回の計算では固定値とせず、\(\mu(T_f)\) と \(k(T_f)\) から毎回計算する。

---

# 13. Rayleigh数の温度依存式

Rayleigh数は、

\[
Ra_D
=
\frac{
g\beta\Delta TD^3
}{
\nu\alpha
}
\]

である。

ここで、

\[
\Delta T
=
|T_s-T_\infty|
\]

とする。

また、

\[
\beta=\frac{1}{T_f}
\]

である。

さらに、

\[
\nu
=
\frac{\mu}{\rho}
\]

\[
\alpha
=
\frac{k}{\rho c_p}
\]

なので、

\[
\nu\alpha
=
\frac{\mu}{\rho}
\frac{k}{\rho c_p}
\]

であり、

\[
\nu\alpha
=
\frac{\mu k}
     {\rho^2c_p}
\]

となる。

したがって、

\[
Ra_D
=
g
\frac{1}{T_f}
\Delta T D^3
\frac{\rho^2c_p}{\mu k}
\]

である。

理想気体式

\[
\rho=\frac{p}{RT_f}
\]

から、

\[
\rho^2
=
\frac{p^2}{R^2T_f^2}
\]

なので、

\[
Ra_D
=
g
\frac{1}{T_f}
\Delta T D^3
\frac{
p^2c_p
}{
R^2T_f^2\mu k
}
\]

となる。

したがって、

\[
\boxed{
Ra_D(T_s,T_\infty,D)
=
\frac{
g\,|T_s-T_\infty|\,D^3\,p^2c_p
}{
R^2T_f^3
\mu(T_f)k(T_f)
}
}
\]

となる。

ここで、

\[
\boxed{
T_f
=
\frac{T_s+T_\infty}{2}
}
\]

である。

これによって、Rayleigh数が表面温度と周囲温度の関数として明示的に表現された。

---

# 14. Churchill–Chuによる水平円柱のNusselt数

水平円柱についてChurchill–Chuの平均Nusselt数相関式を使用する。

\[
\boxed{
Nu_D
=
\left[
0.60
+
\frac{
0.387Ra_D^{1/6}
}{
\left[
1+
\left(
\frac{0.559}{Pr}
\right)^{9/16}
\right]^{8/27}
}
\right]^2
}
\]

この式は水平円柱の自然対流についてChurchillとChuが整理した経験相関式であり、広いRayleigh数範囲を一つの式で連続的に扱える。

文献では概ね

\[
10^{-5}<Ra_D<10^{12}
\]

程度の広い範囲に適用される相関として扱われている。

注意すべき点は、係数

\[
0.60,\quad0.387,\quad0.559
\]

および指数

\[
\frac16,\quad
\frac9{16},\quad
\frac8{27}
\]

はNavier–Stokes方程式から解析的に導出した値ではなく、理論的な漸近特性と実験結果を組み合わせて構成された相関式の係数である。

したがって、

「Rayleigh数とPrandtl数が自然対流を支配する」

ところまでは基礎方程式から導出できるが、

「Churchill–Chu式の数値係数」

については経験相関である。

---

# 15. 対流熱伝達率の最終式

Nusselt数の定義

\[
Nu_D
=
\frac{hD}{k}
\]

から、

\[
h
=
\frac{k}{D}Nu_D
\]

である。

Churchill–Chu式を代入すると、

\[
\boxed{
h(T_s,T_\infty,D)
=
\frac{k(T_f)}{D}
\left[
0.60
+
\frac{
0.387Ra_D^{1/6}
}{
\left[
1+
\left(
\frac{0.559}{Pr(T_f)}
\right)^{9/16}
\right]^{8/27}
}
\right]^2
}
\]

となる。

ここで、

\[
T_f
=
\frac{T_s+T_\infty}{2}
\]

\[
Pr(T_f)
=
\frac{\mu(T_f)c_p}{k(T_f)}
\]

\[
Ra_D
=
\frac{
g|T_s-T_\infty|D^3p^2c_p
}{
R^2T_f^3
\mu(T_f)k(T_f)
}
\]

である。

したがって最終的には、

\[
\boxed{
h
=
f(T_s,T_\infty,D,p)
}
\]

という温度依存の自然対流熱伝達率が得られる。

---

# 16. 計算手順

実際の熱計算では、最初に

\[
T_f
=
\frac{T_s+T_\infty}{2}
\]

を計算する。

次に膜温度 \(T_f\) において、

\[
\rho(T_f)
\]

\[
\mu(T_f)
\]

\[
k(T_f)
\]

を計算する。

続いて、

\[
\nu
=
\frac{\mu}{\rho}
\]

\[
\alpha
=
\frac{k}{\rho c_p}
\]

\[
Pr
=
\frac{\nu}{\alpha}
\]

を求める。

次に、

\[
Ra_D
=
\frac{
g\beta|T_s-T_\infty|D^3
}{
\nu\alpha
}
\]

を求める。

Churchill–Chu式から、

\[
Nu_D
\]

を計算し、最後に、

\[
\boxed{
h=\frac{kNu_D}{D}
}
\]

を求める。

# 18. 表面温度による熱伝達率の変化

周囲温度を

\[
T_\infty=25^\circ\mathrm{C}
\]

に固定した場合の計算結果を以下に示す。

| 表面温度 \(T_s\) | D=10 mm | D=20 mm | D=30 mm | D=50 mm |
|---:|---:|---:|---:|---:|
| 40℃ | 7.35 | 5.88 | 5.28 | 4.71 |
| 60℃ | 8.80 | 7.16 | 6.48 | 5.84 |
| 80℃ | 9.69 | 7.93 | 7.22 | 6.53 |
| 100℃ | 10.33 | 8.50 | 7.74 | 7.02 |
| 125℃ | 10.95 | 9.03 | 8.24 | 7.48 |
| 150℃ | 11.44 | 9.45 | 8.63 | 7.84 |

単位はすべて

\[
\mathrm{W/(m^2K)}
\]

である。

表面温度が高くなるにつれて浮力が増加するため、

\[
Ra_D\uparrow
\]

となり、

\[
Nu_D\uparrow
\]

したがって、

\[
h\uparrow
\]

となる。

一方、円柱直径が小さいほど同じ温度条件における平均熱伝達率 \(h\) は大きくなる。

ただし放熱量は、

\[
Q_{\mathrm{conv}}
=
h\pi DL(T_s-T_\infty)
\]

なので、\(h\) が大きいからといって小径円柱の放熱量が大きいとは限らない。

---

# 19. \(T_s=T_\infty\) の扱い

表面温度と周囲温度が完全に等しい場合、

\[
\Delta T=0
\]

なので、

\[
Q_{\mathrm{conv}}=0
\]

である。

Churchill–Chu式では、

\[
Ra_D\rightarrow0
\]

のとき

\[
Nu_D\rightarrow0.60^2=0.36
\]

となるため、形式的には有限な \(h\) が得られる。

しかし、

\[
Q=hA\Delta T
\]

なので、

\[
\Delta T=0
\]

では熱流はゼロである。

したがって \(T_s=T_\infty\) ちょうどの点で得られる \(h\) の値そのものには、通常の熱設計上、大きな意味を持たせない方がよい。

---

# 20. 熱回路モデルへの組み込み

熱回路では対流熱抵抗を固定値として、

\[
R_{\mathrm{conv}}
=
\frac{1}{hA}
\]

と置くことが多い。

しかし自然対流の場合、

\[
h=h(T_s,T_\infty)
\]

なので、正確には、

\[
\boxed{
R_{\mathrm{conv}}(T_s,T_\infty)
=
\frac{
1
}{
h(T_s,T_\infty)\pi DL
}
}
\]

という非線形熱抵抗になる。

したがって発熱体温度を未知数とする場合には、

\[
Q
=
h(T_s,T_\infty)
A
(T_s-T_\infty)
\]

を満足する \(T_s\) を反復計算によって求める必要がある。

例えば内部発熱量 \(P\) が既知なら、

\[
P
=
h(T_s,T_\infty)
A(T_s-T_\infty)
\]

を \(T_s\) について解けばよい。

放射を含める場合には、

\[
P
=
Q_{\mathrm{conv}}
+
Q_{\mathrm{rad}}
\]

として、

\[
P
=
h(T_s,T_\infty)A(T_s-T_\infty)
+
\varepsilon\sigma A
\left(
T_s^4-T_\infty^4
\right)
\]

とする。

この場合、対流と放射の両方が非線形になる。

# 21. このモデルの適用上の注意

今回求めた \(h\) は、静止した十分広い空間内に置かれた水平円柱の「平均自然対流熱伝達率」である。

したがって、実機に壁面、筐体、隣接部品、バスバー、別の発熱体などが近接する場合には、自然対流流路が拘束され、この式からずれる可能性がある。

また、わずかでも外部から空気流が加わると自然対流だけではなく混合対流になる。

さらに実測した発熱量から

\[
h
=
\frac{Q}{A(T_s-T_\infty)}
\]

を逆算する場合、\(Q\) に放射熱が含まれていると、この値は純粋な対流熱伝達率ではない。

その場合には、

\[
Q_{\mathrm{conv}}
=
Q_{\mathrm{total}}-Q_{\mathrm{rad}}
\]

として放射成分を差し引いてから、

\[
h
=
\frac{
Q_{\mathrm{conv}}
}{
A(T_s-T_\infty)
}
\]

を求める必要がある。
